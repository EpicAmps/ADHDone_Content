# ADHDone! Content Library

Public, versioned content for the [ADHDone! iOS app](https://github.com/EpicAmps/ADHDone). The app supplies native behavior and templates; this repository supplies editable exercises, prompts, and celebrations.

## Files
- `manifest.json` — content release and collection index.
- `content/activation.json` — activation techniques.
- `content/mindfulness.json` — guided resets.
- `content/celebrations.json` — reinforcement messages.
- `schemas/content.schema.json` — collection schema.
- `docs/PUBLISHING.md` — publishing and compatibility instructions.

## Principles
Offline-first, nonjudgmental, opt-in, and evidence-informed. Content updates do not install executable code. Only supported template types can be published without an app release.

**Status:** Initial sample content and contract; the iOS content loader and CDN hosting are not yet implemented.
